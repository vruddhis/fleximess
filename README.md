# fleximess

This is a project that consolidates data from all different hostels across campus, along with their nutrition information, to help users make a more informed decision on where to eat and also track their past meals.

## Key Features
* **Hostel Menu Consolidation:** View daily meals from different campus hostels in one place.
* **Nutrition Information:** Check nutritional details to make healthier food choices.
* **Meal Tracking:** Keep a log of your past meals.
